# 缺失感知的记忆形成

## 候选研究项目介绍

> 当前状态：候选研究方向，尚未确认为 MemoryRush 的正式研究路线。

## 项目概述

缺失感知的记忆形成（Missingness-Aware Memory Formation）研究一个容易被忽略的问题：

> 当 AI 的长期记忆无法支持一个未来问题时，它能否判断信息为什么不存在？

AI 通常会把长文档、历史对话或过去经验压缩成较短的长期记忆。由于未来会遇到什么问题无法提前确定，这种压缩必然可能舍弃以后有用的信息。

当系统之后找不到答案时，至少存在两种本质不同的原因：

1. 原始信息源从未提供答案。
2. 原始信息源提供过答案，但答案在记忆形成过程中被遗漏了。

现有系统经常把这两种情况都表现为“没有找到相关信息”或“我不知道”。本项目希望让长期记忆不仅保存它知道什么，还能帮助系统判断它为什么不知道。

## 直观例子

假设一篇论文写道：

> 该方法在三个数据集上的平均准确率提高了 4.2%，但论文没有报告推理延迟。

经过压缩后，AI 的长期记忆只保留了：

> 该方法在多个数据集上提高了准确率。

此时有两个问题：

### 问题一：准确率提高了多少？

原文包含“4.2%”，但压缩记忆没有保留它。这属于**记忆遗漏**。

系统不应该简单回答“不知道”，因为答案仍然存在于原始信息源中。真正的问题发生在记忆形成过程中。

### 问题二：推理延迟是多少？

压缩记忆中没有答案，原文中也没有答案。这属于**来源沉默**。

这不是记忆系统丢失了信息，而是原始信息源本来就没有提供该信息。系统应该说明来源没有报告，而不是把责任归因于记忆压缩。

这两个问题在表面上都表现为“记忆中没有答案”，但它们对应不同的事实状态、系统责任和后续行为。

## 核心问题

本项目关心的不是一般意义上的“AI 能否回答问题”，而是更细致的问题：

> 当长期记忆不能回答时，系统能否可靠地区分信息源本身的空白、记忆形成造成的遗漏、已有证据带来的矛盾，以及暂时无法确定的情况？

这一问题可以被称为**记忆缺失归因**（Memory Missingness Attribution）。

它把传统的二元判断：

```text
有答案 / 没答案
```

扩展为对“没答案”的原因进行区分：

```text
信息得到支持
原文有信息，但记忆遗漏
原文没有提供信息
问题与已有证据矛盾
当前证据不足以判断
```

## 研究目标

本项目希望建立一种新的长期记忆观念：

> 好的记忆不只需要保存事实，还需要保留对自身信息边界的认识。

围绕这一观念，项目关注三个目标：

### 1. 让“未知”具有可解释的类型

系统不再把所有缺失统一表达为“不知道”，而是说明不知道的原因。

### 2. 让记忆形成过程可以被追责

如果原文包含答案而记忆没有保留，系统应把它识别为记忆形成阶段的遗漏，而不是误认为信息源没有说明。

### 3. 让未来问题暴露记忆边界

由于未来问题不可预先穷举，记忆是否充分不能只在写入时决定。未来问题本身也是检验记忆覆盖范围的重要信号。

## 核心概念

### 来源沉默

来源沉默（Source Silence）表示原始材料没有提供回答某个问题所需的信息。

例如，论文没有报告推理延迟，会议记录没有提到预算，用户从未表达过某项偏好。这些都不是压缩错误。

### 记忆遗漏

记忆遗漏（Memory Omission）表示信息曾经存在于原始材料中，但没有被长期记忆保留下来。

这种情况反映了记忆选择、抽取或压缩带来的损失。

### 记忆失真

记忆失真（Memory Distortion）表示长期记忆保留了相关内容，但改变了原始含义，例如丢失否定、条件、时间范围或不确定性。

它不同于完全遗漏，因为系统看似记住了内容，却可能形成错误结论。

### 证据矛盾

证据矛盾（Contradiction）表示问题中的前提或已有记忆与原始证据不一致。

此时系统需要识别并指出冲突，而不是把它当作普通的信息不足。

### 无法确定

无法确定（Unknown）表示当前证据不足以可靠判断缺失来自哪里。

保留这一状态很重要，因为“暂时没有找到”不等于“原文一定没有”。

## 研究价值

### 更可靠的拒答

系统可以区分“材料没有说明”和“自己的记忆丢失了”，从而减少错误拒答和无依据猜测。

### 更可信的长期记忆

长期记忆不再只是压缩后的事实集合，而是带有来源边界和认知边界的可检查表示。

### 更清楚的错误诊断

当系统回答失败时，可以进一步判断问题发生在信息源、记忆形成还是证据理解阶段，而不只报告最终答案错误。

### 面向未知未来问题

传统压缩往往根据当前可见目标决定保留什么。本项目承认未来问题无法完全预测，因此重点研究系统如何面对压缩后才暴露的信息缺口。

## 与现有研究的区别

与本项目相邻的研究通常关注：

- 长期记忆能否正确召回过去的信息；
- 上下文是否足以回答当前问题；
- 系统在证据不足时能否拒绝回答；
- 信息是在记忆写入阶段丢失，还是在检索阶段没有找到；
- 压缩记忆不足时是否需要重新查阅原始记录。

这些研究为本项目提供了重要基础，但本项目关注一个更具体的对象：

> 把“缺失发生在哪里、为什么发生”本身作为长期记忆需要表示和评估的问题。

它研究的不是单纯提高检索准确率，也不是让模型更频繁地拒答，而是让系统能够解释并区分不同来源的未知。

## 潜在创新点

本项目可能形成的核心创新是：

1. 将长期记忆失败重新定义为一个缺失来源归因问题。
2. 明确区分来源沉默与记忆遗漏，而不是把两者统一视为无答案。
3. 把信息边界视为长期记忆内容的一部分。
4. 用未知的未来问题检验记忆形成质量，而不仅依据预设问题评价压缩结果。
5. 将最终回答错误追溯到信息源、记忆形成和证据判断等不同层次。

## 研究边界

本项目主要研究长期记忆在未知未来问题下的信息边界，不等同于：

- 普通文档问答或聊天机器人；
- 单纯提高向量检索召回率；
- 一般性的模型置信度估计；
- 只判断问题是否可以回答；
- 保存全部原文来避免任何信息损失；
- 预测未来可能出现的所有问题。

项目也不假设长期记忆能够提前记录原文没有提到的所有内容。真正需要研究的是：当具体问题在未来出现后，系统如何识别该信息缺口属于哪一种情况。

## 与 MemoryRush 的关系

MemoryRush 当前关注把长文转换为少量、带有原文证据、适合后续召回的记忆单元。缺失感知的记忆形成可以在这一基础上进一步追问：

> 当这些记忆单元不足以支持未来问题时，系统能否知道是原文没有说，还是自己的记忆形成过程没有保留下来？

两者在研究主题上自然衔接。不过，本方向目前仍处于讨论阶段，尚未取代 MemoryRush 已有的研究规格和计划。

## 一句话总结

> 缺失感知的记忆形成，研究的是让 AI 不仅知道自己“不知道”，还知道这种不知道究竟来自信息源的空白，还是来自自身记忆的遗漏。

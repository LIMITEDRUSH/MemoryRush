## 5. Semantic model execution is not yet a public reproduction command

Do **not** manually call Ollama over all benchmark cases. The protocol requires
the following to be committed and pushed first:

1. inference-only runner that cannot access benchmark oracle or outer mapping;
2. outer-only parser/evaluator that joins oracle only after raw responses seal;
3. fail-closed environment/model/prompt/manifest preflight artifact;
4. immediate immutable PREPARED and terminal attempt persistence;
5. clean Git and exact model digest/version/hardware checks;
6. a CLI whose dry-run/canary/full modes are covered by adversarial tests.

Until those conditions hold, there is no valid command in this document for a
36-case model run. Any ad-hoc output would be `INVALID_RUN` and must not be
silently promoted into the result set.
